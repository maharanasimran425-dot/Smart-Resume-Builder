📄 Smart Resume Builder (AI Powered)
An AI-powered **Smart Resume Builder** built with **Streamlit** and **Google Gemini API**.  
This application generates a **professional, well-structured resume** based on user inputs such as education, skills, and projects.
🚀 Features
- 🧠 AI-generated professional resume
- 📑 Well-formatted sections (Education, Skills, Projects, etc.)
- 🖼️ Clean and interactive Streamlit UI
- ⚡ Fast resume generation using **Gemini 2.5 Flash**
- 📝 Automatically adds a professional summary
- 🎯 No extra or unnecessary text in output

 📸 How It Works

1. Enter personal and professional details
2. Click **Generate**
3. AI creates a structured, attractive resume instantly
